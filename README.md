# Minecraft Skin

La Barista Gentile is a Minecraft skin project that generates a classic 64 × 64 pixel skin in the standard wide-arm model. The skin features a barista cap, a green apron, café-colored details, and a friendly face, with an HTML preview and a button to download the skin as a PNG.

## Install

1. Download or clone the project files.
2. Keep `minecraft_barista_skin.html` and `barista_description.txt` together. No build tools or external dependencies are required.
3. Open `minecraft_barista_skin.html` in a web browser.

## Use

1. View the skin in the page preview.
2. Select “Scarica skin PNG” to download `minecraft-barista-skin.png`.
3. Import the PNG into your Minecraft profile and choose the standard wide-arm model.
